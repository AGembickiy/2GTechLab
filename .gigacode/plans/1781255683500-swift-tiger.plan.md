# План полного рефакторинга проекта 2GTechLab

## Общая цель
Провести комплексный рефакторинг проекта 3D-печати с фокусом на оптимизацию структуры кода, улучшение читаемости, устранение дублирования и обеспечение работоспособности на каждом этапе.

## Анализ текущего состояния
- Backend: Django + DRF + Celery
- Frontend: Nuxt 3 (Vue 3)
- База данных: PostgreSQL
- Дублирование моделей (shop/models.py, orders/models.py, print_service/models.py)
- Разрозненная архитектура сервисов
- Отсутствовали единые стандарты кодирования

## Инструкция по запуску

### Для запуска проекта:
```bash
cd /home/g/2GTechLab
bash run.sh
```

### Для ручного запуска:
```bash
# Backend
cd /home/g/2GTechLab
source venv/bin/activate
python manage.py runserver 0.0.0.0:8000

# Frontend
cd /home/g/2GTechLab/frontend
npm run dev
```

### Для администратора:
- URL: http://localhost:8000/admin/
- Логин: admin
