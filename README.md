# 2GTechLab - Платформа для 3D-печати

Платформа для 3D-печати с интерактивным онлайн-редактором 3D моделей.

## Структура проекта

```
2GTechLab/
├── frontend/          # Nuxt 3 приложение (Vue 3)
├── backend/           # API сервер (скелет)
├── scripts/           # Вспомогательные скрипты
├── logs/              # Логи запуска
├── run.sh             # Основной скрипт запуска
└── Makefile           # Утилиты Make
```

## Технологический стек

| Компонент | Технология | Назначение |
| :--- | :--- | :--- |
| Frontend | Nuxt.js 3 / Vue.js 3 | Пользовательский интерфейс |
| UI Framework | Nuxt UI | Компоненты интерфейса |
| Styling | Tailwind CSS | Стилизация |
| Type Safety | TypeScript | Типизация |
| State Management | Pinia | Управление состоянием |
| 3D Graphics | Three.js | 3D рендеринг |

## Архитектура Frontend

### Компоненты (components/)
- **common/** - общие компоненты (Header, Hero, Slider)
- **order/** - компоненты заказов
- **printers/** - компоненты принтеров
- **ui/** - переиспользуемые UI элементы
- **ThreeViewer.vue** - основной 3D редактор

### Сторы (stores/)
- **auth.ts** - аутентификация и роли
- **api.ts** - глобальное состояние API
- **cart.ts** - корзина
- **material.ts** - материалы
- **order.ts** - заказы
- **printer.ts** - принтеры
- **message.ts** - сообщения
- **transaction.ts** - транзакции

### Страницы (pages/)
- **admin/** - панель администратора
- **auth/** - аутентификация
- **catalog/** - каталог моделей
- **client/** - клиентская зона
- **manager/** - менеджер зона
- **partner/** - партнерская зона

### Утилиты (utils/)
- **three/** - Three.js утилиты
- **api.ts** - API хелперы
- **format.ts** - форматирование данных
- **validation.ts** - валидация

## Возможности

- Загрузка и редактирование 3D моделей
- Онлайн-редактор с масштабированием, вращением и покраской
- Предпросмотр моделей в формате GLB
- Расчет стоимости доставки
- Размещение заказов
- Управление ролями пользователей
- Аналитика и отчеты

## Запуск проекта

### Быстрый старт

```bash
# Запуск всего проекта (frontend + backend)
./run.sh
```

Этот скрипт автоматически:
- Проверит зависимости (bash, node, npm)
- Установит node_modules если нужно
- Запустит frontend и backend в фоне
- Обработает Ctrl+C для корректной остановки
- Сохранит логи в `logs/` директорию

### Ручной запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build

# Предпросмотр продакшн сборки
npm run preview
```

Frontend будет доступен по адресу: `http://localhost:3000`

## Использование Make

```bash
# Установка зависимостей
make install

# Запуск frontend
make frontend

# Запуск backend
make backend

# Проверка кода
make lint

# Форматирование кода
make format

# Очистка node_modules
make clean
```

## Логи

Логи запуска доступны в `logs/`:

```bash
cat logs/frontend.log
cat logs/backend.log
```

## Остановка проекта

При нажатии **Ctrl+C** все процессы будут корректно остановлены.

Или вручную:

```bash
pkill -f "nuxt dev"
pkill -f "node.*backend"
```
