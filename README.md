# Финальная спецификация: Платформа 3D-печати v2.0

## 1. Концепция
Создание интеллектуальной экосистемы для 3D-печати, которая автоматизирует не только технические процессы (нарезка), но и бизнес-процессы (логистика, склад, партнерская программа), предоставляя при этом пользователю инструменты для самостоятельной подготовки модели.

## 2. Архитектура системы

*   **Клиентское приложение (Frontend):** Vue.js / Nuxt.js.
*   **Серверная часть (Backend):** Django / Django Rest Framework (DRF).
*   **Фоновые задачи (Workers):** Celery + Redis.
*   **Административная панель (Admin Panel):** Кастомное SPA на Vue.js.

---

## 3. Обновленный сценарий работы (User Flow)

### Путь клиента (Frontend) — Улучшенный UX

1.  **Загрузка и Редактирование:**
    *   Пользователь загружает файл. Система автоматически определяет формат.
    *   Открывается **Онлайн-редактор**. Пользователь может:
        *   **Масштабировать:** Изменить размер модели с сохранением пропорций.
        *   **Вращать:** Расположить модель на виртуальном столе для экономии материала или повышения качества.
        *   **Красить:** Выбрать элементы и задать им цвет и материал из каталога.
2.  **Предпросмотр:** Модель отображается в формате **GLB** с примененными изменениями.
3.  **Логистика:** Система автоматически рассчитывает стоимость доставки через API (например, СДЭК) на основе габаритов посылки и адреса клиента.
4.  **Заказ:** Нажатие кнопки «Разместить заказ».

### Путь файла (Backend / Celery) — Улучшенная автоматизация

1.  **Получение задачи:** Воркер берет заказ из очереди.
2.  **Автоматический Ремонт и Подготовка:**
    *   `trimesh` загружает файл.
    *   Система проверяет модель на герметичность (`is_watertight`).
    *   Если найдены мелкие ошибки, `pymeshfix` автоматически их исправляет. Если модель критически повреждена, заказ ставится на паузу с уведомлением админа.
3.  **Оптимизация и Конвертация:**
    *   Если в заказе несколько моделей, система применяет алгоритм **Nesting** для их оптимального размещения на столе принтера.
    *   Модель конвертируется в **STL** и в цветной **3MF** с применением инструкций по материалам.
4.  **Нарезка (Слайсинг):**
    *   `CuraEngine` нарезает `3MF` файл.
    *   Генерируется **G-code** и статистика (вес, время, расход по цветам).
5.  **Расчет цены:**
    *   Система агрегирует данные: время печати, расход материалов, стоимость логистики (из API), расходы на упаковку, ставку часа (из «Финансов»).
    *   Рассчитывается финальная стоимость.
6.  **Финализация:** Сохранение всех данных. Статус заказа: «Готов к оплате».

## 4. Обновленная структура административной панели (Vue.js)

Панель управления с доступом по логину/паролю `admin`.

1.  **Заказы:**
    *   Воронка статусов: `Новый` -> `На ремонте` -> `В нарезке` -> `Готов к печати` -> `Передан в логистику` -> `Доставлен`.
    *   Карточка заказа: Детальная информация, ручное изменение цены, история статусов.
2.  **Финансы:**
    *   Управление ставками часа, расходами на упаковку.
    *   Управление тарифами логистики (интеграция с API СДЭК/Почты).
    *   Ввод постоянных расходов (аренда, сервер, реклама).
    *   Налоговые настройки.
3.  **Оборудование:**
    *   Реестр принтеров.
    *   Журнал ТО и статистика брака.
4.  **Склад:**
    *   Учет остатков филамента, сопел, упаковки.
    *   Система уведомлений о низком уровне запасов (например, < 100г пластика).
5.  **Пользователи и Партнеры:**
    *   Разделение на **Заказчиков** и **Партнеров** (дизайнеры).
    *   CRM-функции: История заказов, сегментация клиентов («Новый», «VIP»).
    *   Управление «Магазином» моделей партнеров и выплатами комиссионных.
6.  **Аналитика (Новое):**
    *   Дашборд с ключевыми метриками:
        *   Выручка и прибыль за период.
        *   Самые прибыльные материалы и принтеры.
        *   Средний чек заказа.
        *   ROI рекламных кампаний.

## 5. Технологический стек

| Компонент | Технология | Назначение |
| :--- | :--- | :--- |
| Frontend | Vue.js / Nuxt.js | Пользовательский интерфейс сайта |
| Backend API | Django / DRF | Серверная логика, база данных |
| Admin Panel | Vue.js | Кастомная панель управления |
| Очередь задач | Celery + Redis | Фоновые задачи (обработка файлов) |
| Работа с 3D | `trimesh`, `pymeshfix` | Конвертация, ремонт геометрии |
| Оптимизация | Алгоритмы Nesting | Умное размещение моделей на столе |
| Слайсинг | CuraEngine / PrusaSlicer | Генерация G-code |
| Логистика | API СДЭК / Почты РФ | Автоматический расчет доставки |
| База данных | PostgreSQL | Хранение всех данных |
